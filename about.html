About

What is WinHash#?

WinHash is a complete, privacy-first encryption and hashing toolkit that runs entirely inside your browser. It began as a small desktop utility and grew into a full web platform for protecting text, images, video, audio and documents — with nothing ever sent to a server.

Privacy by design

There is no backend. Every operation uses the browser’s built-in Web Crypto API, so your files and passwords stay on your device. You can go offline and it still works.

Broad coverage

Classical ciphers for learning, AES-256 and ChaCha20 for real encryption, RSA for asymmetric use, and 13 hash algorithms for integrity and signatures.

Strong crypto standards

Keys are derived with PBKDF2-HMAC-SHA256 at 600,000 iterations with random salts. Authenticated modes detect tampering and wrong passwords safely.

Open & documented

The file format is a documented binary container (.wnh) and the code is open source, so you can verify exactly how your data is handled.

Security notice

Read this before relying on it

WinHash is provided for education and convenience. It uses well-known, standard algorithms, but no tool can guarantee absolute security. For high-stakes or professional use, consider a formally audited solution and keep your passwords and keys in a reputable password manager.

Key points:

  • Classical ciphers (Caesar, Vigenère, Rail Fence, etc.) are educational only — never use them for real secrets.
  • MD5 and SHA-1 are broken for security purposes; they remain only for legacy compatibility and checksums.
  • CRC32 and FNV-1a are checksums, not encryption — they provide no secrecy.
  • If you lose your password or private key, encrypted data cannot be recovered — by design.
  • The .wnh container protects file contents and metadata, but the file size is still visible to observers.
